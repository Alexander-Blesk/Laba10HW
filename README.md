# Laba10HW
# Домашняя работа (Условие)

Составить программу с использованием пользовательских функций и меню выбора для работы с геометрической фигурой. Программа должна позволять вычислять площадь фигуры, выводить её определение, рисовать фигуру в консоли заданным символом и сравнивать площади двух фигур.


# Алгоритм

- Начало.

- Настройка русской локализации (setlocale(LC_ALL, "RUS")).

- Вывод меню операций на экран в цикле do-while до тех пор, пока пользователь не введёт 0:

- 1 — вызов функции area_figure() для расчёта и вывода площади фигуры;

- 2 — вызов функции print_definition() для вывода текстового определения фигуры;

- 3 — ввод размера сетки (не менее 5) и символа, вызов функции draw_figure(draw_h, ch) для отрисовки фигуры в системе координат;

- 4 — ввод параметров, расчёт площадей двух фигур и вызов функции compare_figures(c1, c2) для их сравнения;

- 0 — завершение работы программы.

- Конец.
